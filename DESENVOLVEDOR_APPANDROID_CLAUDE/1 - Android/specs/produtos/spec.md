# Produtos da Loja

## Objetivo
Exibir os produtos do restaurante selecionado.

## Cabeçalho
Exibir:
- nome
- avaliação
- categoria
- tempo de entrega

## Produtos
Cada produto deve possuir:

- imagem
- nome
- descrição
- preço

## Comportamento
Ao selecionar um restaurante na Home:
abrir esta tela exibindo seus produtos.
