# Login

## Objetivo
Permitir que o usuário entre no aplicativo.

## Interface
A tela deve possuir:

- título "Entrar"
- campo de e-mail
- campo de senha
- botão "Entrar"

## Comportamento
Ao tocar em Entrar:

- validar campos
- navegar para Home

## Observação
Não utilizar autenticação real nesta versão.
