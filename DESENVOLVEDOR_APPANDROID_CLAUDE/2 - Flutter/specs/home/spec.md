# Home

## Objetivo
Exibir restaurantes disponíveis.

## Interface
Exibir:
- saudação
- localização
- campo de busca
- categorias
- lista de restaurantes

## Restaurante
Cada restaurante deve possuir:

- imagem
- nome
- categoria
- avaliação
- tempo de entrega

## Comportamento
Ao tocar em um restaurante:
abrir a tela de produtos daquele restaurante.
